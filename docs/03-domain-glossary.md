# 03 · Domain Glossary

Scaffolding terms as Airwright uses them.

| Term | Meaning |
|------|---------|
| **LM** | Linear metres — the unit scaffold is measured/priced in. |
| **Lift** | A working level, ~2m of height. Jobs are counted and priced lift by lift. 2-storey ≈ 4 lifts, 2.5-storey ≈ 5. |
| **Perimeter** | Total run of external scaffold per lift. Assembled from individual wall lengths, **+1 LM per corner/return**. |
| **Birdcage** | Internal scaffold filling a floor area (safety deck), measured in **m²**. One per storey (GF, FF…). |
| **Gable / Apex** | Triangular wall top under a **pitched** roof; needs extra scaffold. A **hipped** roof has none. Counted as a quantity. |
| **Gable rails** | Rails to the apex; usually matches the gable count. |
| **Render** | Extra scaffold across a rendered elevation section. Priced length × lifts (often 3 lifts, not 4). Varies **per plot**. |
| **Low level** | Scaffold for low features — porches, bay windows. A quantity. |
| **Foot scaffold** | Low ground-level scaffold. |
| **Haki** | Proprietary stair tower (access). Client-specified. |
| **Ladder tower** | Alternative access to Haki. |
| **LB / Loading bay** | Where materials are loaded onto the scaffold. Per lift; shared across a block. |
| **Rubbish chute / skip bay** | Waste route. Per lift; shared across a block. |
| **Table lift** | A component in the staged pay/quote. |
| **Joist support / props** | Supports the structure when stairs go in (single / double / sacrificial — spec-driven). |
| **Party wall** | Shared wall between two houses. Detached = none; semi = one. |
| **Erect vs Dismantle** | Put up vs take down — priced as separate operations. |
| **Configuration** | Detached / Semi / End-terrace / Mid-terrace. Changes which walls get scaffold and the LM. Mid-terrace shares two walls; end/semi one; detached none. |
| **JG** | Joint gable — a gable shared between two houses. |
| **Take-off** | The measured list of scaffold quantities/operations for a house type. |
| **Handover** | Certificate the gang signs when a stage is complete; triggers pay + client billing. |
| **Hire weeks** | How long the scaffold stays rented up (construction). |
| **TG20** | The scaffold design compliance standard. |
| **Rate band** | Super competitive / competitive / medium / high / custom — Colin's commercial pricing tier. |
| **Strike** | The incumbent desktop software being replaced. Alpha Estimator (pricing) + Job Manager (billing). |
